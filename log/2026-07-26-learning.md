## 设计哲学
### 有界记忆
MEMORY.md 2200 字符限制不是缺陷，是刻意设计。有限空间迫使 Agent 学会计 priority。
[Source: Hermes 官方文档 + 白皮书, 2026-07-26]

### 渐进式披露
技能按需加载，不复用时不加载。分三级：索引 → 内容 → 引用文件。
[Source: Hermes 官方文档, 2026-07-26]

### 事件优先于日志
状态变更走结构化事件而非自然语言推断。对用户报告时也应分层级：摘要结论 > 细节证据。
[Source: claw-code ROADMAP.md, 2026-07-26]

### 结构胜过灵活
4 个核心 skill 比 400 个垃圾 skill 有用。克制扩展，质量优先。
[Source: Gajae Code AGENTS.md, 2026-07-26]

### 验证驱动
每次执行不说完事，保留证据链。Oracle 验证通过才算完成。
[Source: claw-code + LazyCodex, 2026-07-26]

### Clawable 设计
CLI 应满足：启动确定、状态可读、失败可恢复、事件优先。
[Source: claw-code ROADMAP.md, 2026-07-26]
