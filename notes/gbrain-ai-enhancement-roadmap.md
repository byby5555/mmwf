# gbrain AI 增强待办

用户担心后面会忘记这些方向，因此记录下来。

## 建议优先级

1. VPS 资产盘点 → 定时扫所有 VPS，把 CPU/RAM/磁盘/服务/用途/异常写入 gbrain。
2. Deal/优惠转发 → 用户转发 VPS offer 后，结构化提取商家、配置、价格、优惠码、优缺点、适合场景，写入 gbrain。
3. Anki 生成 → 使用 DeckMasterPro 模板生成 APKG，并把生成记录/来源写回 gbrain。
4. 每日简报 → 从 gbrain 拉最近 VPS、deal、学习、任务上下文，早上推送。

## 当前判断

不建议另起一套大型 AI 系统。继续用 Hermes + gbrain，当作个人 AI 操作系统，在现有系统上加小能力最划算。
