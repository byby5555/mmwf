# 论文文笔改造指南（正式版）

用户写毕设（基于 SpringBoot 的个人博客系统）时，需要对文字进行「降级」处理。

## 核心目标

看起来像「本科生自己写的第一遍稿子」，通过朱雀 AI 人工检测。

## 改造规则（按优先级）

1. **句式**：减少句号使用，多用逗号串联，一逗到底。把长句拆成短句，两三个短句用逗号串起来。
2. **词汇**：专业词换通俗说法（实现→弄出来/做出来，执行→跑，验证→看/检查，构建→搭，部署→放上去），多用「搞、弄、管、做、弄出来」这类词
3. **语序**：打乱句子原有结构，改成把字句、被动句，灵活互换。补充无主句的主语。
4. **口语化**：适当加入「它、那个、还有、就是、也、了、一下」这类词，比如「系统它」「数据管起来」「也还行」。但不能太多变成口水话。
5. **字数**：原文总字数 ±15% 浮动。小于350字的段落要扩展到350字以上才能过朱雀检测。
6. **删除**：删掉「我觉得、我认为、综上所述、本文」这类主观表述和论文套路词。删掉太啰嗦的口水化表达。
7. **整体感**：看起来像作者写得很吃力、勉强写完的，语句不够精炼，有冗余感。

## 示例对照

| 原文 | 改后 |
|------|------|
| 系统实现了用户注册登录功能 | 用户可以注册一个账号，注册完了就能登录进去 |
| 前端采用 Vue.js 框架进行开发 | 前端用了 Vue.js，页面就是这样弄出来的 |
| 经过系统测试验证，本系统运行稳定 | 测完以后功能都能用，跑起来也比较稳定 |

## 朱雀验证记录

- 2026-07-23：版本A（一逗到底+口水词）→ 100%人工 ✅
- 2026-07-23：版本B（规整短句）→ 未发现明显人工特征 ❌

结论：用版本A风格。
