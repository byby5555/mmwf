# Dream Cycle

gbrain 夜间 8 阶段自动维护，凌晨 2 点运行：

1. **Entity Sweep** — 发现新实体
2. **Citation Audit** — 修复引用断链
3. **Memory Consolidation** — 跨会话合并
4. **Graph Extraction** — 知识图谱链接
5. **Takes Scoring** — 可信度评分
6. **Embed Update** — 向量更新
7. **Sync** — git 同步
8. **Skill Optimization** — 路由评估
