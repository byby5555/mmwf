# MECE Knowledge Directory

Mutually Exclusive, Collectively Exhaustive。gbrain 的知识组织原则：

| 目录 | 用途 |
|------|------|
| people/ | 每人一页，frontmatter + timeline |
| companies/ | 每公司一页 |
| concepts/ | 思维模型、方法论 |
| projects/ | 在建项目 |
| deals/ | 投资交易 |
| meetings/ | 会议记录 |
| ideas/ | 未概念化想法 |
| sources/ | 原始数据（邮件原文等） |
| reference/ | 参考信息 |
| health/ | 健康记录 |
| inbox/ | 暂存笔记 |
