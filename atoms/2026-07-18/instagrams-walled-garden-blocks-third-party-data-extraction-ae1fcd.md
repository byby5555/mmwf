Attempting to extract metadata from a private platform like Instagram reveals a fundamental asymmetry: the platform holds all the data and strictly controls access via authentication and API restrictions. Without direct HTTP request tools or user credentials, even the most persistent automated search efforts cannot retrieve basic Reel metadata such as caption, publisher, or engagement counts.
