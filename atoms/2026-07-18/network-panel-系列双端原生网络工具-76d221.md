Network Panel 为 Android（Java）和 iOS（SwiftUI）提供了原生网络流量面板，支持实时速率、线路管理、数据用量统计，iOS 版还包含地区延迟检测和多主题，且可通过 GitHub Actions 自动构建 IPA。虽然是初期项目（⭐ 1-2），但两端的覆盖思路值得关注。
