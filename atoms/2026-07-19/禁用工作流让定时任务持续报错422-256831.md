GitHub Actions 工作流被人为禁用后（state: disabled_manually），通过 dispatch API 触发会恒返回 HTTP 422。此时 cron 定时任务沦为无效噪音，要么删除任务消除报错，要么改为提醒用户手动操作。用户之前决定关闭 Actions 手动上传，但对应定时任务没有清理，导致每天 9 点准时报错。
